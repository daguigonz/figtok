# Intro
FigTok is a free plugin that converts Figma design tokens into CSS, JSON, and more. Perfect for designers and developers looking for visual consistency and fast delivery. Customize prefixes, export instantly, and copy with one click. Simple, fast, and productive.

You can view the current project interfaces at the following link:
[Figma file](https://www.figma.com/file/3r2G00brulOwr9j7F6JF59/Figma-Design-System?node-id=0%3A1)

## Objectives & Benefits
<br />
<div class="grid-container" >
  <div class="">

  ### Consistency

  The user interface is built from a set of modular components like `Button`, `Switch`, and `Block`. By reusing these core elements, we ensure a consistent visual language and user experience across the entire plugin, from layout to interaction.

  </div>

  <div class="">
  ### Collaboration

  A well-documented component library acts as a shared resource for the development team. This common ground simplifies communication, streamlines the integration of new features, and makes the codebase easier to understand and contribute to.

  </div>

  <div class="">
  ### Efficiency

  By breaking the UI down into minimal, reusable components, we significantly increase development speed. This approach reduces redundant code, simplifies testing, and allows for rapid prototyping and iteration of new interface designs.
  
  </div>
</div>
